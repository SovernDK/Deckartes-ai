# CS tools (`cs_api.py`)

Matches, teams, players and tournaments come from PandaScore's `/csgo` routes. The free plan has no stats routes (they return 403), so player rating/K-D isn't available. It has no age in player search either; that's read from the team's roster. HLTV itself is behind Cloudflare and can't be reached with httpx. The ranking is Valve's Regional Standings: the newest `live/<year>/standings_<region>_<date>.md` from the ValveSoftware GitHub repo, parsed from its markdown table. PandaScore and Valve name some teams differently ("Team Falcons" vs "Falcons"), so `_valve_rank` drops filler words and falls back to 3+ shared roster players. PandaScore can't filter matches by tier, so "all" lists are filtered locally to `config.cs_min_tier`, but they also keep any match with a team from Valve's top `MAJOR_TEAM_RANK`, since top teams play small events too. A started match is `running`, not `upcoming`, in PandaScore, so per-team upcoming lists and `get_cs_team` also query `/matches/running`. Past "all" results are also re-sorted and capped at 30 days, because the API's sort lets in stale forfeits. Teams are searched by name and acronym, with exact matches and teams that have a roster first ("Spirit", not "Spirit Academy"). PandaScore finds nothing for a misspelt name, so then `_closest` picks the closest team or player in Valve's global standings (`names.closest_name`, `token_set_ratio` ≥ `NAME_CUTOFF`, the higher-ranked on a tie) and searches again with it; the tool text starts with `No team is named "…"; the closest match is:`. A misspelt team outside Valve's standings still finds nothing. Match responses are cached for 60s, everything else for an hour. Each public function at the bottom of `cs_api.py` takes a tool's arguments and returns tool text, joining a private fetch step (slim dicts holding real values; missing data is `None` or `[]`) to a private wording step. `_match_line(match, team)` writes a team's own matches from its side ("won 3-0 vs MOUZ") and other results as "X beat Y 2-0", so the model can't mix up whose score is whose. Match lists are grouped under day headings with times.
