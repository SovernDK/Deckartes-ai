# Anime tools (`animeschedule_api.py`)

Results are slimmed to name/rating/episodes/date and rated shows at or below `config.anime_min_rating` (0–10 scale, converted from the API's 1–100) are dropped. Unrated shows (`ratingCount` 0) stay, with `rating: None`, and sort last. They also sort last on the API side, so every page of a list is fetched. Timetables have no ratings, so they're matched by `route` against all `ongoing` anime, because season lists only contain premieres from that season. Timetable `week` is the ISO week, and `subPremier` is `0001-01-01` when unset. `top_season_anime` takes relative seasons ("next", "previous") so the model doesn't do season arithmetic. Upcoming seasons have few ratings, so it fills the top N with unrated shows by `trackedCount` and says so in a `note`. `continues_next_season` estimates the final episode from the next timetable episode plus the announced count at one a week, and answers `"unknown"` with a reason when either is missing. The tools return text from the `*_text` formatters at the bottom of the module; the data functions above them still return slim dicts. List headers state shared context once (season, rating cutoff, "episode counts and premiere dates are given only when announced"), and unknown values are left out rather than spelled "not announced" on every line. `user_list_text` groups shows under "Airing today/tomorrow/later this week/next week" headings, because small models filtered a flat list for "this week" unreliably. `continues_text` leads with "will NOT be airing next season", because "continues next season: no." was read as a yes. Airing lines put the name first, because "14:31 FX Fighter…" was read as a channel called FX. The season list is capped at `MAX_SEASON_LIST`. Responses are cached for an hour (the limit is 120 requests per minute). Some anime have no `names` key. `user_list` reads `config.animeschedule_user`'s public list with the app token (the `/animelists/oauth` routes need OAuth2) and is read-only on purpose. It's cached for only 60s, and English names come from the ongoing-anime cache so they match the airing tool. Each entry also gets its next subtitled episode from this and next week's timetables, so questions like "which of my shows air this week" need one tool call. Small models don't reliably chain the day-by-day airing tool themselves.
