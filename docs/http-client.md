# HTTP client (`http_client.py`)

The web backends (Glances, web search, AnimeSchedule, PandaScore, Valve's GitHub standings) call `http_client.request(method, url, name=..., error=...)`. It returns the 200 `httpx.Response` and raises the backend's own exception class for everything else, with the message the model gets: "Could not reach {name}", "No {name} token: set {token_env}…" (`token=""`), "{name} rate limit reached, resets at…" (from `x-ratelimit-reset`), `status_messages` overrides (PandaScore's 403 "not in the plan"), or "{name} responded with status N: <body start>". `max_age` caches 200 responses in memory by method, url and params. `http_client.pages(fetch, page_size, max_pages)` owns paging through a list: the backend's `fetch(index)` builds the request and returns `(items, total)`, and `pages` applies the cap and the stop rule (the API's total, or with `None` a short page). Tests swap `http_client._transport` for an `httpx.MockTransport` (`tests/test_http_client.py` covers the module and one tool per backend), so a new backend should use `request` too.
